# Skills IVAO Perú

Colección de skills de Claude para los departamentos de la división peruana de IVAO.

| Skill | Departamento | Descripción |
|---|---|---|
| [ivao-peru-eventos](ivao-peru-eventos/) | Eventos | Busca huecos en calendar.ivao.aero, reserva el evento, genera el BBCode (ES/EN), el prompt del banner, el mensaje a Operaciones y los recordatorios en Google Calendar. |

## Instalación

Cada skill vive en su propia carpeta. Para usar una:

- **Claude.ai / app de Claude:** comprime la carpeta de la skill en un `.zip` y súbela en Ajustes → Capacidades → Skills.
- **Claude Code:** copia la carpeta en `~/.claude/skills/`.
